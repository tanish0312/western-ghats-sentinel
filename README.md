# 🌿 Western Ghats Sentinel

### Tree Cover • Carbon • Conservation

An interactive environmental intelligence dashboard exploring
tree-cover loss, carbon-related indicators, spatial patterns and
conservation-status information across the Western Ghats study region.

---

## 🌍 Project Overview

Western Ghats Sentinel is a data analytics and environmental
intelligence application developed to transform environmental datasets
into an interactive research dashboard.

The project focuses on five states:

- Karnataka
- Kerala
- Tamil Nadu
- Goa
- Maharashtra

The dashboard brings together:

- Forest-loss analysis
- Spatial analysis
- Carbon and emissions indicators
- Conservation-status analysis
- Statistical relationships
- Lag analysis
- Interactive data exploration
- Executive-level insights
- Automated project reporting

---

## 🎯 Project Objective

The objective is to create an analytical system that allows users to
investigate environmental pressure across the Western Ghats study
region.

The project focuses on:

1. Measuring annual tree-cover loss.
2. Comparing forest loss across states.
3. Normalizing loss using spatial area.
4. Examining carbon-related indicators.
5. Exploring conservation-status information.
6. Investigating statistical relationships.
7. Presenting the results through an interactive dashboard.

---

## ❓ Research Questions

The project investigates:

- How has tree-cover loss changed over time?
- How does forest loss differ among the study states?
- Which states show greater normalized loss intensity?
- How are tree-cover loss and carbon-related indicators associated?
- What patterns are visible in conservation-status data?
- Are there observable lagged relationships?
- What are the analytical limitations of the available datasets?
